# Lab design system

Lab is a quiet, monochrome tool. The interface should disappear behind the
conversation.

## Principles

- **Monochrome first.** Color comes from the neutral scale. The only hue is
  `destructive`, for errors and irreversible actions.
- **Tokens, not values.** Every color, radius, and shadow comes from
  `src/index.css`. Tailwind's default palette is removed, and
  `oxlint-tailwindcss` rejects arbitrary values like `pb-[12vh]` and default
  palette colors outside `components/ui`.
- **Content over chrome.** Prefer whitespace and type weight to borders and
  boxes. Use a border only when it separates two surfaces.
- **One way to do each thing.** Reach for an existing component before writing
  markup, and add new primitives with `bunx shadcn add` so they follow the same
  conventions.

## Accessibility

- Text meets WCAG 2.2 AA contrast: 4.5:1, or 3:1 at 24px and above.
- Focus is always visible. Rings use the `ring` token, which stays above 3:1
  even at half opacity.
- Interactive targets are at least 24px, and 32px or more for primary actions.
- Motion respects `prefers-reduced-motion` through `MotionConfig` and
  `motion-safe:`.

Every story is a test. `bun run --filter @lab/web test` renders each story in
Chromium and fails on axe violations.

## Working with components

- `components/ui` holds shadcn components. Edit them in place; don't wrap them
  to restyle.
- Variants live in `cva` definitions next to the component, and `cn` merges
  overrides.
- App components live in `components/` and get a story under **Patterns**.
