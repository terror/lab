## Guidelines

- Use `text-sm` for interface text and `text-base` for conversation content.
- Use weight, not size, for hierarchy within a block: `font-medium` for names,
  `font-semibold` for titles.
- Use `text-muted-foreground` for anything secondary instead of a smaller size.
- Use `tabular-nums` for numbers that change in place.
