# Color

Neutrals are OKLCH values defined in `:root` and `.dark`, then mapped to
utilities in `@theme inline`. Use the semantic token, never a raw value. Each
swatch reads its value from the stylesheet and shows it in light and in dark.

## Spark

Chrome is monochrome. Color belongs to the agent. The spark palette is the three
hues of the Lab mark. A spark hue appears only when Lab is working, when it
finishes something, when it needs you, or in an illustration. Never use one on
navigation, buttons, or borders, and use at most one hue in a component.

- **Coral** means Lab needs you: an unread chat, a question that waits.
- **Blue** means Lab is working: a live run, a step that just finished.
- **Yellow** means done: completion, celebration, something remembered.

Each hue has three tiers.

- **Raw** is for decoration only: the mark, dots, confetti, illustration. It
  fails contrast as text on light surfaces.
- **Ink** is for text and icons. `contrast.test.ts` fails if an ink drops below
  4.5:1 on any surface, or on its own wash, in either theme.
- **Wash** is a tinted background. Put only ink of the same hue on it.

Lint rejects spark utilities outside `components/ui`. To put a spark color on a
screen, use a status token, or a component that carries the color, such as
`LiveMark` or `Dot`. Inside `components/ui`, lint rejects raw or wash as a text
color and any spark on a border, ring, or outline.

## Status

Feature code names what a color means, never the hue. Three status tokens alias
the spark palette, each with the same three tiers.

- **Attention** is coral: Lab needs you, or something is unread.
- **Live** is blue: Lab is working on it now.
- **Done** is yellow: finished.

<Unstyled>
  <Swatches
    tokens={[
      { description: 'Raw.', name: 'status-attention' },
      { description: 'Ink.', name: 'status-attention-ink', pair: 'background' },
      {
        description: 'Wash.',
        name: 'status-attention-wash',
        pair: 'status-attention-ink',
      },
      { description: 'Raw.', name: 'status-live' },
      { description: 'Ink.', name: 'status-live-ink', pair: 'background' },
      {
        description: 'Wash.',
        name: 'status-live-wash',
        pair: 'status-live-ink',
      },
      { description: 'Raw.', name: 'status-done' },
      { description: 'Ink.', name: 'status-done-ink', pair: 'background' },
      {
        description: 'Wash.',
        name: 'status-done-wash',
        pair: 'status-done-ink',
      },
    ]}
  />
</Unstyled>

Use `bg-status-attention`, `text-status-live-ink` and so on. The same rules hold
as for spark: at most one hue in a component, raw and wash never as a text
color, ink never faded, and no status on a border, ring, or outline. Lint
enforces the last three wherever a class name is written.
