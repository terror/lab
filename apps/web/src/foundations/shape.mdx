# Shape and elevation

Radii scale from `--radius` (0.625rem). Larger containers get rounder corners.
Four role tokens name the steps that components share. The values below are read
from the stylesheet.

A few shapes keep their own step.

Nested corners are concentric: the inner radius is the outer radius minus the
padding between them. A menu is `rounded-menu` with 4px of padding, so its items
are `rounded-sm`.

## Elevation

Elevation is rare. Menus, popovers, and hover cards use `shadow-md` with a
`ring-1 ring-foreground/10` edge. Dialogs and sheets use `shadow-lg`. The
composer uses `shadow-sm`. Everything else is flat. Separate surfaces with
background color before reaching for a border or shadow.
