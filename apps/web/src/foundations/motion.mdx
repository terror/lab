# Motion

Motion explains change. It never decorates. Frequent interactions get fast,
quiet feedback, and a rare moment gets one short flourish.

## Guidelines

- Use the `shimmer` utility for live status text, like the activity line while a
  reply is thinking.
- Stream answers with Streamdown's word fade rather than animating whole blocks.
- Slow a loop down once it has run for 5 seconds.

## Reduced motion

- `MotionConfig reducedMotion='user'` drops transforms and layout animation from
  Motion components and keeps opacity.
- One media query in `index.css` removes travel and zoom from every `animate-in`
  and `animate-out`, keeps the fade, and makes accordions instant.
- Guard a CSS loop with `motion-safe:`. `shimmer` turns itself off.
